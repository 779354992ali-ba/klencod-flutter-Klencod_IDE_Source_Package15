# Klencod IDE – Package 15: Dedicated Full-Screen Editor

## المشكلة التي يعالجها التحديث

في واجهة الهاتف كانت مساحة المحرر تتقلص بسبب ظهور شريط التبويبات وأدوات الملفات وشريط الحالة، خصوصًا عند فتح لوحة المفاتيح. كما أن وضع ملء الشاشة السابق كان تبديلًا داخل الصفحة نفسها وليس شاشة مستقلة.

## التغيير

- الضغط على أيقونة `</>` في الشريط العلوي يفتح شاشة مستقلة للمحرر عبر `MaterialPageRoute`.
- شاشة المحرر الجديدة تستخدم `CodeController` نفسه للتبويب الحالي، لذلك تبقى النصوص والتحديدات والتعديلات دون نسخ أو فقدان.
- تختفي واجهة المستكشف وأزرار إدارة الملفات وشريط الحالة أثناء التحرير في الشاشة المستقلة.
- مساحة المحرر تتمدد لتشغل المساحة المتاحة بالكامل، مع أرقام الأسطر وتلوين الأكواد.
- يتوفر في الشاشة المستقلة زر رجوع، حفظ، إكمال تلقائي، وتكبير/تصغير الخط.
- عند الرجوع تعود واجهة IDE الرئيسية كما كانت.
- أزيل محرر الصفحة الرئيسية مؤقتًا قبل فتح الشاشة الجديدة لتجنب ربط `CodeController` بأكثر من `CodeField` في الوقت نفسه.

## الملفات المعدلة

- `lib/main.dart`

## التحقق

تم التحقق من سلامة أرشيف ZIP بعد إنشائه. لم تتوفر Flutter/Dart SDK في بيئة إعداد الحزمة، لذلك يجب تشغيل `flutter analyze` و`flutter test` ثم بناء APK على Termux أو GitHub Actions.
